# IEEE GRSS Student Branch Chapter, IISER Bhopal

Website of the IEEE Geoscience and Remote Sensing Society Student Branch Chapter at IISER Bhopal (unit SBC60206905, GRS29).

Live site: https://geoai4cities.github.io/grss/

## Editing

Plain HTML and CSS, no build step. Each page is one file:

| File | Page |
| --- | --- |
| `index.html` | Home |
| `about.html` | About IEEE GRSS and the chapter |
| `team.html` | Faculty and officers |
| `events.html` | Upcoming events, calendar, past events |
| `talks.html` | Expert Talk Series |
| `join.html` | Membership and contact |
| `assets/css/site.css` | Shared styles |
| `assets/img/` | Logos, officer photos, posters, QR codes |

To add an event: add a card under "Upcoming" in `events.html`, a row in the calendar table, and after the event move it to "Past events". For a talk, add a section to `talks.html` with the poster in `assets/img/events/`.

Commit to `main` and GitHub Pages republishes within a minute.
